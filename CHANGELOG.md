## 0.1.0 - Initial Release

### Storefront

- Server-side rendered e-commerce storefront with Axum and Askama templates
- Shopify Storefront API integration for products, collections, and cart
- Subscription support with Shop Pay installments
- Product filtering, sorting, and variant selection
- Full-text search powered by Tantivy
- Blog and static pages content system with Markdown and image shortcodes
- Newsletter signup with Klaviyo integration
- Customer authentication via Shopify Customer Account API with WebAuthn passkeys
- PostgreSQL session management
- Build-time image optimization with Cloudflare Image Resizing proxy
- Tailwind CSS 4.0 with responsive design
- HTMX-powered interactivity
- Security headers, CSP nonce support, and rate limiting
- SEO metadata and structured data
- Analytics integration (Mixpanel, Pinterest, TikTok, Cloudflare Web Analytics)
- Sentry error monitoring with user context and breadcrumbs

### Admin

- Internal admin panel accessible via Tailscale VPN
- Shopify Admin API integration with OAuth authentication
- AI chat assistant powered by Claude with Shopify tool use
- Order, customer, product, collection, inventory, discount, and gift card management
- ShipHero warehouse integration for inventory and order visibility
- Channel analytics dashboard with ShopifyQL
- Manufacturing cost tracking
- Payout management
- Newsletter and SMS marketing system
- Invite-based setup flow with passkey-only authentication
- Midnight Lagoon dark theme with Morning Shade light mode

### Infrastructure

- Multi-stage Docker builds with cargo-chef for dependency caching
- Fly.io deployment with staging and production environments
- CI/CD pipeline with lint, test, build, and deploy stages
- Database isolation between storefront and admin
- Structured JSON logging with OpenTelemetry conventions
- Semantic versioning enforcement with cocogitto
