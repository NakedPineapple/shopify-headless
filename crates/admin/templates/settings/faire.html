About Faire Integration

Faire is a B2B wholesale marketplace connecting brands with independent retailers. Connecting to Faire allows you to manage wholesale orders, track returns and payouts, monitor retailer relationships, and analyze your wholesale channel performance.

Required credentials: You need a Faire Brand account with API access. Obtain your Brand ID and API Token from the Faire Brand Portal.

Note: Only Super Admins can manage Faire settings. All credentials are stored securely and redacted in logs.
