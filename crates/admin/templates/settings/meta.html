About Meta Commerce Integration

Connecting to Meta Commerce allows you to manage your Facebook and Instagram shops directly from this admin panel. View catalog products, manage product mappings, track orders across channels, and monitor sales analytics.

Required credentials: You need a Meta app with Commerce API access, a Page Access Token with the appropriate permissions, and your Commerce Account and Catalog IDs. See the Meta Commerce Platform documentation for setup instructions.

Note: Only Super Admins can manage Meta Commerce settings. All credentials are stored securely and redacted in logs.
