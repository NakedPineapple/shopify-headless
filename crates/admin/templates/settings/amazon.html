About Amazon SP-API Integration

Connecting to the Amazon Selling Partner API allows you to view Amazon-specific data including FBA inventory levels, Amazon orders, ASIN mappings, and competitive pricing directly in this admin panel.

Required credentials: You need a Login with Amazon (LWA) application with SP-API access, plus AWS IAM credentials authorized for SP-API signing. See the SP-API documentation for setup instructions.

Note: Only Super Admins can manage Amazon SP-API settings. All credentials are stored securely and redacted in logs.
