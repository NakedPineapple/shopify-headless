Security & Reliability

Built to Be Secure

Multiple layers of protection keep your business data safe and your customers' information private — without you having to think about it.

Login Security

  • No passwords — sign in with Face ID, fingerprint, or device PIN
  • Login sessions expire automatically after inactivity
  • Fresh security token generated every time you sign in

Private Access

  • Admin panel hidden from the public internet entirely
  • All traffic encrypted — browsers forced to use secure connections
  • Cloudflare protection against traffic floods and attacks

Attack Prevention

  • Every form protected against forgery and impersonation
  • Strict rules prevent malicious code from running on pages
  • Automatic lockout after too many failed login attempts
  • All user input checked and cleaned before processing

Data Isolation

  • Customer data and business data stored in separate databases
  • Passwords and keys automatically erased from memory when not in use
  • Database queries verified at build time — data theft structurally impossible
